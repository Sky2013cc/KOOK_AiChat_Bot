# KOOK_AiChat_Bot
轻松的在kook平台上接入你的个人AI对话，只需要填入你的API即可马上开始！
已写入完整计费系统，开箱即用，包含API计费，每日签到，模型费率，兑换系统，邀请系统，当然，你也可以直接使用without_limit版本来无限制使用（无计费系统）
我会持续维护这个项目，并且我会更新他，现在可能有很多的不足，希望你可以把问题反馈给我！

---

轻松的部署这个项目！
1.你需一个python环境！我使用的版本是python 3.12，我在代码中加入了一些兼容性修复，你可以用最新的3.14版本来运行他
2.以下是需要的库：
```python
pip install khl.py openai psutil
```
3.把py文件用IDLE打开，修改文件中的token，api，apikey等信息，然后记得要修改模型列表！一定要与你的模型提供商提供的模型名称一致！
4.F5启动即可！如果你收到了“就绪”的提示，说明你的机器人已经成功的启动了！去kook试一试吧

---

以下是用户可以使用的指令！
1.'/c [内容]'和'/chat [内容]'
与 AI 发起对话，例如 /c 你好，请自我介绍。
2.'/help'
获取所有的用户指令
3.'/money'
查看当前账户余额、当前使用的模型、计费倍率以及上下文记忆开关状态。
4.'/sign'
每日签到，获取1-5w token
5.'/redeem [卡密]'
激活账户，分为“激活码”（管理员生成）和“邀请码”（用户消耗1.2w token生成面值1w token邀请码，邀请码用户将不能签到）
6.'/list'
当前你设置的模型列表
7.'/models [模型名]'
切换当前用户使用的模型
8.'/上下文开启 / /上下文关闭'
是否启用上下文，默认8条，可在文件中修改
9.'/online [开/关]'
开关联网搜索，需要模型支持联网搜索（可能以后会改成自动爬取）
10.'/invite'
用户生成邀请码，消耗1.2w余额
