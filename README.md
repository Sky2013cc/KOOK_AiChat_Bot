# KOOK_AiChat_Bot
轻松的在kook平台上接入你的个人AI对话，只需要填入你的API即可马上开始！

已写入完整计费系统，开箱即用，包含API计费，每日签到，模型费率，兑换系统，邀请系统，当然，你也可以直接使用withoutlimit版本来无限制使用（无计费系统）

我会持续维护这个项目，并且我会更新他，现在可能有很多的不足，希望你可以把问题反馈给我！

1.0.0版本的help指令有些混乱，用的是老版本测试阶段的指令，建议自己改一下

轻松的部署这个项目！
---


1.你需一个python环境！我使用的版本是python 3.12，我在代码中加入了一些兼容性修复，你可以用最新的3.14版本来运行他

2.以下是需要的库：
```python
pip install khl.py openai psutil
```

3.把py文件用IDLE打开，修改文件中的token，api，apikey等信息，然后记得要修改模型列表！一定要与你的模型提供商提供的模型名称一致！

4.F5启动即可！如果你收到了“就绪”的提示，说明你的机器人已经成功的启动了！去kook试一试吧

commands
---

以下是用户可以使用的指令！

• 1./c [内容]'和'/chat [内容]
与 AI 发起对话，例如 /c 你好，请自我介绍。

• 2./help
获取所有的用户指令

• 3./money
查看当前账户余额、当前使用的模型、计费倍率以及上下文记忆开关状态。

• 4./sign
每日签到，获取1-5w token

• 5./redeem [卡密]
激活账户，分为“激活码”（管理员生成）和“邀请码”（用户消耗1.2w token生成面值1w token邀请码，邀请码用户将不能签到）

• 6./list
当前你设置的模型列表

• 7./models [模型名]
切换当前用户使用的模型

• 8./上下文开启 / /上下文关闭
是否启用上下文，默认8条，可在文件中修改

• 9./online [开/关]
开关联网搜索，需要模型支持联网搜索（可能以后会改成自动爬取），开启以后1.1倍计费

• 10./invite
消耗 12,000 Token 生成一个面额 10,000 的邀请码，供他人激活使用（最多生成 3 次）

• 11./delete confirm
永久删除所有的个人信息，注销账号

管理员指令如下

•/add [用户ID] [数量]
为指定用户手动充值 Token。例如 /add 123456 50000。

•/addmodel [模型名称] [费率]
热更新添加新模型支持并设置计费倍率。例如 /addmodel o1-mini 1.5。

•/status
查看服务器主机的实时状态（系统版本、CPU、内存、运行时间）。

•/dashboard
查看全局数据（总用户数、全服总余额、剩余卡密、财富榜前 3 名）。

•/restart
远程重启机器人进程。

•/clean
给数据库瘦身，彻底删除已经使用过的失效卡密。

•/check [用户ID]
查询指定用户的详细状态（余额、封禁状态、联网状态、激活类型等）。

•/reset [用户ID]
强制清除某人的今日签到记录，使其可以再签到一次。

•/broadcast [内容]
发送系统公告（注：代码存在缺陷）。

•/create [面额] [数量]
批量生成充值卡密。例如 /create 10000 5（默认生成 1 张面额 800000 的卡密）。

•/ban [用户ID] / /unban [用户ID]
封禁或解封指定用户

•/usage [小时数]
统计过去 X 小时内的全服对话次数和总 Token 消耗。例如 /usage 24。

•/rate [模型名称] [费率]
动态调整已有模型的计费倍率。
